# Project 4: Titanic Passenger Data, Vectors, Factors and Subsetting

**Course:** TDM 101

## Overview
Introductory R data wrangling using the Titanic passenger dataset: exploring vector types, subsetting data frames, and recoding numeric columns into readable categorical factors to visualize survival patterns.

## Techniques
- Data frame inspection (`str`, `summary`)
- Vector creation and type checking (`class`, `typeof`, `mode`)
- Conditional subsetting/filtering (missing values, age thresholds)
- Recoding numeric codes into factors (`factor()`) for passenger class and survival status
- Bar plots and mosaic plots of survival by gender and age group

## Key Finding
Recoded passenger class and survival status into readable labels, then visualized survival outcomes broken down by gender and by age bracket using a mosaic plot.

## Data
- `titanic.csv`: small, safe to include in `data/`
