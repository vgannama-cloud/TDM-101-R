# Project 6: Control Flow, Conditionals and Loops

**Course:** TDM 101

## Overview
Practice with R control flow: if/else logic (mapped to a lightsaber color example), vectorized conditional recoding, and while/repeat loops applied to a social media usage dataset and a Star Wars characters dataset.

## Techniques
- `if`/`else if`/`else` branching
- Vectorized conditional labeling (`ifelse`, nested `ifelse`)
- `while` loops and `repeat` loops
- Comparing loop-based vs vectorized approaches to the same computation

## Key Finding
Classified social media users into usage/sleep categories (healthy vs excessive use) using vectorized logic, then compared a manual loop-based species count against a fully vectorized equivalent on a Star Wars characters dataset to show both approaches give the same result.

## Data
- `social_media.csv`, `characters.csv`: small, safe to include in `data/`
