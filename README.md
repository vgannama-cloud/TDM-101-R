# TDM 101, Data Mine Seminar Projects (R)

Weekly data science projects completed as part of Purdue's Data Mine seminar (TDM 101), using R for exploratory data analysis, statistical techniques, and reproducible workflows.

## Projects

| # | Project | Dataset / Topic | Key Techniques | Link |
|---|---------|------------------|-----------------|------|
| 01 | Flights and Olympics Frequency Analysis | Airports, 2007 flights, Olympic athletes | EDA, `fread`, dot charts | [project-01](./project-01-flights-olympics) |
| 02 | Rotten Tomatoes Movie Ratings | Rotten Tomatoes movies | Data cleaning, cross-tabs, mosaic plot | [project-02](./project-02-rotten-tomatoes) |
| 04 | Titanic, Vectors, Factors and Subsetting | Titanic passengers | Factors, subsetting, mosaic plot | [project-04](./project-04-titanic) |
| 05 | Flights and Ice Cream, Grouped Aggregation | Flights, ice cream ratings | `tapply`, `cut()` binning, heatmaps | [project-05](./project-05-flights-icecream) |
| 06 | Control Flow, Conditionals and Loops | Social media usage, Star Wars characters | if/else, while, repeat loops | [project-06](./project-06-control-flow) |
| 07 | YouTube and Taylor Swift, Custom Functions | YouTube channels, TS discography | String cleaning, custom functions | [project-07](./project-07-youtube-taylorswift) |
| 08 | Dates and Times, Orders and Flights | Restaurant orders, flights | `lubridate`, timestamp reconstruction | [project-08](./project-08-dates-times) |

## Tech Stack

R, tidyverse (dplyr, ggplot2), patchwork, lubridate, data.table, Jupyter (IRkernel)

## About

Part of Purdue's [Data Mine](https://datamine.purdue.edu/) program, a data science learning community. Each notebook was completed individually as part of the weekly seminar curriculum.
